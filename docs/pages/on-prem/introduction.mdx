# Introduction

Welcome to Authenta On-Prem! This documentation will guide you through deploying and using Authenta's deepfake detection system in your infrastructure.

## What is Authenta On-Prem?

Authenta On-Prem is our enterprise-grade deepfake detection solution that runs completely within your infrastructure. It provides:

- 🔒 Full data sovereignty and privacy
- 🏢 Complete offline operation capability
- ⚡ High-performance AI inference
- 🔄 Simple updates and maintenance

## Key Features

- **Offline Operation**: Run entirely within your network with no external dependencies
- **GPU-Accelerated Inference**: The default deployment runs on NVIDIA GPU hardware
- **Horizontal Scaling**: Deploy multiple workers for increased throughput
- **Simple Integration**: A single REST API (the Authenta API Server) for job creation, upload, and results
- **Active Monitoring**: Health endpoints and worker fleet visibility via the API
