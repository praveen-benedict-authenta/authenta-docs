# API Explorer

Try the Authenta API from your browser: authorize with your `api_...` key, then run the four steps in order. Downloadable spec: <a href="/openapi/authenta-api.yaml" download>authenta-api.yaml</a> (import it into Postman or any OpenAPI tool).

:::warning
Calls to `https://platform.authenta.ai` from this page are currently blocked by the browser ("Failed to fetch"). Until that's enabled, use the requests here as a reference and run them with curl or Postman, or pick the **On-prem / self-hosted** server if your deployment allows browser access.
:::
