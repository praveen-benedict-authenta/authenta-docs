# API Explorer

Try the Authenta API from your browser: authorize with your `api_...` key, then run the four steps in order. Downloadable spec: <a href="/openapi/authenta-api.yaml" download>authenta-api.yaml</a> (import it into Postman or any OpenAPI tool).

:::info
Requests go from your browser straight to the selected server. On-prem servers allow this site by default; if yours sets `CORS_ORIGINS`, include `https://docs.authenta.ai` in it, or run the requests with curl or Postman.
:::
