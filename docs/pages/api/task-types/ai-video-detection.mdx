# AI Video Detector

Checks whether a video was generated by an AI video model.

| Slug | ID | Status | Tagged | Model version |
|---|---|---|---|---|
| `ai-video-detection` | `3` | Active | Yes | `v2` |

## What it detects

| Detects | Does not detect |
|---|---|
| Fully AI-generated video, by analyzing sampled frames | Traditional edits such as cuts, color grading or non-AI visual effects. For face swaps in real footage, use [`ekyc-deepfake`](/api/task-types/ekyc-deepfake) |

## Request

| Slot | Accepted `contentType` |
|---|---|
| `original` | `video/mp4`, `video/mov` |

```json
{
  "taskTypeId": "3",
  "inputs": [
    { "slotName": "original", "fileName": "clip.mp4", "contentType": "video/mp4", "sizeBytes": 5242880 }
  ]
}
```

See [Running a job](/api/reference/jobs#running-a-job) for the full create, upload and finalize flow.

## Limits

- File size: up to the account upload limit, 10 MB by default.
- Only the **first 8 seconds** of the video are analyzed. Trim the clip to the part you want checked.

## Result

Uses the standard [result fields](/api/task-types#result-fields).

```json
{
  "isFake": false,
  "confidencePercent": 99.95,
  "fakeConfidencePercent": 0.05,
  "realConfidencePercent": 99.95,
  "tag": "real",
  "tagBoundaries": { "real": 30, "likelyReal": 50, "likelyFake": 75 },
  "modelVersion": "v2"
}
```

## Output artifacts

| `kind` | File | Description |
|---|---|---|
| `result` | `result.json` | Full result, with the detected frame rate and how many frames were sampled |

Download it from `artifacts` on [`GET /jobs/{id}`](/api/reference/jobs#downloading-files).
